# Project Management Platform

![Project Management Dashboard](/assets/images/projects/PM-Dashboard.webp)

## Project Overview

This is an internal project management platform built us to help manage ongoing development work across multiple internal projects.

The goal is to keep task tracking, deadlines, and team coordination in one place so we don’t rely on scattered tools like spreadsheets, chat threads, and separate trackers.

You can access the platform here: https://pm.big-matrix.com/

## Problem Statement

Before this system, we faced common internal workflow issues:

- Tasks were tracked in multiple places, making it hard to follow progress
- Deadlines were often missed or updated manually
- It was difficult to understand who is working on what
- Project status updates required frequent manual coordination
- Resource workload was not clearly visible across team members

## Our Solution

The platform was designed as a simple system to centralize project work.

It provides:

- Task creation and assignment with deadlines
- Project and task-level progress tracking
- Team workload visibility
- Centralized updates for ongoing work
- A single place to view active projects and their status

## Technology Stack

The system is built using:

- React for the frontend interface
- Django for backend APIs and business logic
- MySQL for data storage

## Key Capabilities

- Task and deadline tracking
- Project and task-level organization of work
- Team coordination and clear visibility of workload
- Dashboard for overall progress

## Purpose and Scope

This platform is designed to reduce manual coordination effort and make project tracking more structured. It helps centralize ongoing work, improve deadline visibility, and give teams a clearer understanding of task responsibility and progress across projects. As a result, overall team efficiency has improved, with smoother collaboration and fewer delays in day-to-day execution.
